# EncryptionUtility

A utility class providing cryptographic operations for password hashing, secure token generation, AES encryption, and hash-based message authentication, designed for secure data handling in .NET applications.

## API

### `HashPassword`

Computes a secure password hash using PBKDF2 with HMAC-SHA256, a random salt, and 100,000 iterations. The resulting hash is encoded in Base64 with the salt prepended.

- **Parameters**
  - `password`: The plaintext password to hash.
- **Returns**
  - A Base64-encoded string containing the salt and hash.
- **Throws**
  - `ArgumentNullException`: If `password` is `null`.
  - `ArgumentException`: If `password` is empty or whitespace.

---

### `VerifyPassword`

Verifies a plaintext password against a stored hash (including salt) generated by `HashPassword`.

- **Parameters**
  - `password`: The plaintext password to verify.
  - `hashedPassword`: The stored hash string (salt + hash).
- **Returns**
  - `true` if the password matches the hash; otherwise, `false`.
- **Throws**
  - `ArgumentNullException`: If either parameter is `null`.
  - `FormatException`: If `hashedPassword` is malformed.

---

### `EncryptAes`

Encrypts a plaintext string using AES-256 in CBC mode with PKCS7 padding. The key and IV are derived from the provided password using PBKDF2.

- **Parameters**
  - `plaintext`: The text to encrypt.
  - `password`: The encryption password.
- **Returns**
  - A Base64-encoded string containing the IV and ciphertext.
- **Throws**
  - `ArgumentNullException`: If either parameter is `null`.
  - `CryptographicException`: If encryption fails (e.g., invalid key size).

---

### `DecryptAes`

Decrypts a ciphertext string encrypted by `EncryptAes`. The key and IV are derived from the provided password using PBKDF2.

- **Parameters**
  - `ciphertext`: The Base64-encoded IV and ciphertext.
  - `password`: The decryption password.
- **Returns**
  - The decrypted plaintext string.
- **Throws**
  - `ArgumentNullException`: If either parameter is `null`.
  - `FormatException`: If `ciphertext` is malformed.
  - `CryptographicException`: If decryption fails (e.g., incorrect password or corrupted data).

---
### `GenerateRandomBytes`

Generates a cryptographically secure array of random bytes.

- **Parameters**
  - `length`: The number of bytes to generate.
- **Returns**
  - A byte array of the specified length.
- **Throws**
  - `ArgumentOutOfRangeException`: If `length` is less than 1.

---
### `GenerateSecureToken`

Generates a cryptographically secure random token string suitable for session IDs or CSRF tokens. The token is Base64-encoded.

- **Parameters**
  - `length`: The length of the token in bytes (before encoding).
- **Returns**
  - A Base64-encoded random token string.
- **Throws**
  - `ArgumentOutOfRangeException`: If `length` is less than 1.

---
### `ComputeHmacSha256`

Computes an HMAC-SHA256 signature for a given message and key.

- **Parameters**
  - `message`: The input message to sign.
  - `key`: The secret key for HMAC.
- **Returns**
  - A Base64-encoded HMAC-SHA256 signature.
- **Throws**
  - `ArgumentNullException`: If either parameter is `null`.

---
### `ComputeSha256`

Computes the SHA-256 hash of a given input string.

- **Parameters**
  - `input`: The string to hash.
- **Returns**
  - A hexadecimal string representing the hash.
- **Throws**
  - `ArgumentNullException`: If `input` is `null`.
