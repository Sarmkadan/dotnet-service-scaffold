# ServiceEvent

Represents an event generated by a service, used for tracking service state changes, errors, warnings, and other notable occurrences within the `dotnet-service-scaffold` framework.

## API

### `Id`
A unique identifier for the event. Automatically assigned when the event is created.

### `ServiceId`
The unique identifier of the service that generated the event. Used to associate the event with its originating service.

### `Service`
A reference to the `ServiceRegistration` associated with this event, if available. May be `null` if the service is not registered or has been removed.

### `EventType`
The type of event, represented by the `ServiceEventType` enum. Determines the nature of the event (e.g., `Started`, `Stopped`, `Error`).

### `Message`
A human-readable message describing the event. May be `null` if no message is provided.

### `CreatedAt`
The timestamp when the event was created. Automatically set to the current UTC time upon instantiation.

### `Severity`
A string indicating the severity of the event (e.g., `Info`, `Warning`, `Error`). May be `null` if not specified.

### `SourceHost`
The hostname or IP address of the machine where the event originated. May be `null` if not applicable.

### `StackTrace`
A string containing the stack trace of an exception, if the event was generated from an error. May be `null` if not applicable.

### `AcknowledgedAt`
A boolean indicating whether the event has been acknowledged. Defaults to `false`.

### `AcknowledgedBy`
The identifier of the user or system that acknowledged the event. May be `null` if not acknowledged.

### `IsAlertWorthy`
A boolean indicating whether the event should trigger an alert. Used to filter events for notification purposes.

### `Acknowledge`
A method that marks the event as acknowledged. Sets `AcknowledgedAt` to `true` and records the current UTC time in `AcknowledgedBy`.

### `GetEventTypeDescription`
Returns a human-readable description of the `EventType`. Useful for logging or UI display.
